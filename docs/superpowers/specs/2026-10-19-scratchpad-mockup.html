Scratchpad: layout mockup

Two versions of the same window. It's a rough sketch to react to, not a final design. Both use the same sample note.

A · Sidebar only

Click a note in the sidebar to switch to it. One note is on screen at a time.

B · Sidebar + tabs

The sidebar works the same way, but you can keep a few notes open as tabs while you move things between them.

What's in the sketch

  1. Pinned notes sit above everything else. (Orange pin.)
  2. Newest first, grouped by day. (The day groups are my guess.)
  3. A note without a title shows its first line in the list. (My guess.)
  4. Checkboxes, bullets, yellow-marker highlight, inline code and a coloured code block.
  5. An image and a file sit inline in the note, where they were pasted or dropped. (My guess.)
  6. One font for the whole note, like Notepad, so anything pasted always matches. (My guess.)
  7. Glass toolbar buttons: pin, attach, new note.
