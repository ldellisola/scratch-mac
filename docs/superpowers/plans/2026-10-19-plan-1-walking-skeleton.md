# Scratch Plan 1: Walking Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A launchable, releasable Scratch 0.1.0. It's one window with a glass sidebar listing notes, a toolbar "new note" button, and a plain-text editor that never needs saving and restores exactly on relaunch. It ships with the CI, screenshot, performance and release loop every later plan relies on.

**Architecture:**

- `Packages/ScratchCore` is a Foundation-only Swift package that builds and tests on Linux and macOS. It holds the note model, the SQLite wrapper, the stores, the autosave policy, launch options and fixtures.
- `App/` is a thin AppKit shell generated by XcodeGen, depending on `ScratchCore`.
- GitHub Actions does all macOS work and publishes its results to an orphan `ci-results` branch, which cloud agents read with git.

**Tech Stack:**

- Swift 6.3.3 in Swift 6 language mode: Xcode 26.6 on CI, the swift.org toolchain on Linux
- AppKit on the macOS 26 SDK
- system SQLite through a `CSQLite` module map
- Swift Testing for core tests, XCTest/XCUITest for app, UI and performance tests
- XcodeGen, `swift format`, GitHub Actions (`macos-26` and the `swift:6.3.3-noble` container)

**Spec:** [`docs/superpowers/specs/2026-10-19-scratchpad-design.md`](../specs/2026-10-19-scratchpad-design.md). Roadmap: [`2026-10-19-roadmap.md`](2026-10-19-roadmap.md).

**Branch:** work on `plan-1-skeleton`, branched from `claude/scratchpad-design`. When every task is done and CI is green, open one PR to `main` and merge it (spec §9.6). Merging publishes the 0.1.0 release (Task 11).

## Global Constraints

These are copied from the spec. Every task implicitly includes them.

**Platform and stack**
- macOS 26 (Tahoe) or later, arm64 (Apple Silicon) only. Deployment target `26.0`.
- Fully native: Swift and Apple frameworks. No web views, Electron, Catalyst or cross-platform UI toolkits.
- Swift 6, strict concurrency checking on.
- AppKit, throughout.
- Liquid Glass comes from system components and materials only. No custom blur or translucency effects.
- Storage is the system SQLite library, with no ORM, in WAL journal mode.
- Tree-sitter is the one significant third-party dependency. Every other dependency needs a decision record. Plan 1 adds no runtime dependency.
- Toolchain pin: CI uses `/Applications/Xcode_26.6.app` (Swift 6.3.3). Linux uses swift.org 6.3.3, and `.swift-version` holds `6.3.3`.
- Bundle identifier: `io.github.ldellisola.Scratch`. Product name `Scratch`.

**Architecture rules**
- `ScratchCore` has no AppKit or SwiftUI imports, and builds and tests with plain `swift test` on Linux.
- App depends on Core, never the other way round.

**Data and privacy**
- The app makes no network requests.
- The app is **not** App Sandboxed. All data lives in `~/Library/Application Support/Scratch/`.
- Tests, screenshots and benchmarks never touch real data. They always run against an isolated data directory (Task 6).

**Editor behaviour**
- Every change is persisted within about one second. Persistence also happens immediately when the app deactivates or quits.
- One monospaced font, SF Mono 13 pt by default.
- Smart quotes, smart dashes and auto-correct are off everywhere in the editor.
- Pasted content always takes the note's font and colours. Copy and Cut put **plain text only** on the pasteboard.
- Closing the window quits the app.

**Performance budgets (spec §7)**

| Scenario | Budget |
|---|---|
| Launch to restored note accepting keystrokes | ≤ 200 ms |
| Keystroke | ≤ 8 ms main-thread work |
| Scrolling | no frame over 8 ms |
| Switching notes | ≤ 8 ms for ≤ 1,000 lines, ≤ 50 ms otherwise |
| Idle | 0% CPU, no timers firing |

CI fails a result that regresses more than 20% against the stored baseline or exceeds twice its budget. It warns when a result is over budget but inside those limits.

## Review Focus

These are the conditions most likely to hurt the owner that the spec implies but never spells out. Each has a test in the task named.

1. **Quitting with ⌘Q within a second of typing** loses nothing. Task 8: `testQuitImmediatelyAfterTypingKeepsText`.
2. **Force-kill or crash** more than one second after the last keystroke loses nothing. Task 8: `testTypedTextSurvivesForceKill`.
3. **Rich text pasted** from a browser or Word lands in the note font, with no foreign font, size or colour. Task 7: `testPastingRichTextUsesNoteFont`.
4. **A restored cursor offset** that falls inside an emoji, or beyond the end of a shorter text, never crashes and lands on a valid boundary. Task 4: the `TextOffset.clamp` tests.
5. **A 50,000-line paste** returns quickly, and saving a multi-megabyte note doesn't block typing. Task 4: `largeBodyRoundTrips`. Task 10: `testInsertingFiftyThousandLinesIsFast`.

    - Polls `git fetch <remote> <branch>` every `CI_WAIT_INTERVAL` seconds (default 30) until `CI_WAIT_TIMEOUT` (default 2700).
    - Prints each `summary.json`.
    - Exits 0 when all succeed, 1 when any fails, 2 on timeout.
  - `scripts/ci-fetch.sh <sha> <dest>` extracts `<sha>/` from the results branch into `<dest>`.
  - `make ci-wait SHA=<sha> [JOBS="linux macos"]`, which passes `JOBS` through to `ci-wait.sh`.

### Task 3: SQLite wrapper and schema v1

**Interfaces:**
- Produces:

```swift
public enum SQLValue: Equatable, Sendable { case null, integer(Int64), real(Double), text(String), blob([UInt8]) }
public struct Row: Sendable {
    public subscript(_ column: String) -> SQLValue? { get }
    public func string(_ c: String) -> String?
    public func int(_ c: String) -> Int64?
    public func double(_ c: String) -> Double?
    public func date(_ c: String) -> Date?    // REAL = timeIntervalSinceReferenceDate
}
public struct DatabaseError: Error, Equatable { public let code: Int32; public let message: String }
public final class Database: @unchecked Sendable {        // all access serialised by an internal Mutex
    public init(path: String) throws                       // ":memory:" allowed
    public func execute(_ sql: String, _ args: [SQLValue] = []) throws
    public func query(_ sql: String, _ args: [SQLValue] = []) throws -> [Row]
    public func transaction<T>(_ body: () throws -> T) throws -> T
    public func userVersion() throws -> Int
}
public enum Schema { public static let currentVersion = 1; public static func migrate(_ db: Database) throws }
public extension SQLValue { static func date(_ d: Date) -> SQLValue; static func optionalDate(_ d: Date?) -> SQLValue }
```

**Schema v1.** `migrate` runs this inside one transaction when `user_version < 1`:

```sql
CREATE TABLE notes (
  id TEXT PRIMARY KEY, title TEXT NOT NULL, body TEXT NOT NULL,
  display_title TEXT NOT NULL, has_title INTEGER NOT NULL, preview TEXT NOT NULL,
  created_at REAL NOT NULL, modified_at REAL NOT NULL, pinned_at REAL, deleted_at REAL);
CREATE INDEX notes_list ON notes(deleted_at, pinned_at, modified_at);
CREATE TABLE session (key TEXT PRIMARY KEY, value BLOB NOT NULL);
PRAGMA user_version = 1;
```

`Database.init` sets these pragmas on file databases:

```sql
PRAGMA journal_mode=WAL;
PRAGMA synchronous=NORMAL;
PRAGMA busy_timeout=2000;
```

```swift
public struct NoteSummary: Equatable, Sendable {
    public let id: NoteID; public let displayTitle: String; public let hasTitle: Bool
    public let preview: String; public let modifiedAt: Date; public let pinnedAt: Date?
}
public final class NoteStore: Sendable {
    public init(database: Database) throws          // calls Schema.migrate
    public func create(now: Date) throws -> Note    // inserts an empty note, created = modified = now
    public func note(_ id: NoteID) throws -> Note?
    public func save(_ note: Note) throws           // upsert; writes display_title/has_title/preview from Note
    public func saveAll(_ notes: [Note]) throws     // one transaction
    public func summaries() throws -> [NoteSummary] // deleted_at IS NULL; pinned first, then modified_at DESC
    public func discard(_ id: NoteID) throws        // hard delete; only for never-used empty notes
}
public struct TabState: Codable, Equatable, Sendable { public var noteID: NoteID; public var selection: Int; public var scrollY: Double }
public struct SessionState: Codable, Equatable, Sendable { public var tabs: [TabState]; public var activeTabIndex: Int }
public final class SessionStore: Sendable {
    public init(database: Database) throws
    public func load() throws -> SessionState?      // nil when absent or undecodable
    public func save(_ state: SessionState) throws  // JSON under key "state"
}
public enum TextOffset { public static func clamp(_ utf16Offset: Int, in text: String) -> Int }
```

Pinned notes are ordered among themselves by `modified_at DESC` too.

```swift
}
public final class ManualAutosaveScheduler: AutosaveScheduler, @unchecked Sendable {
    public init(); public func advance(by: Duration)            // fires due actions synchronously, in order
}
public final class DispatchAutosaveScheduler: AutosaveScheduler { public init(queue: DispatchQueue) }
public final class Autosaver: Sendable {
    public init(policy: AutosavePolicy = .standard, scheduler: any AutosaveScheduler, save: @escaping @Sendable () -> Void)
    public var isDirty: Bool { get }
    public func markDirty()
    public func flush()
}
```

Behaviour:

- When `markDirty` is called while clean, it records `dirtySince = now`.
- Every `markDirty` (re)schedules a single timer at `min(now + quietPeriod, dirtySince + maxDelay)`.
- When the timer fires, or on `flush` while dirty, the saver becomes clean and then calls `save`, outside the lock.
- `flush` while clean does nothing.
- There are no repeating timers, which keeps idle CPU at 0%.

- Produces:

    - Exits 1 when `git diff --name-only <base-ref>...HEAD` touches `App/` or `Packages/` while `VERSION` is identical to `<base-ref>:VERSION`.
    - Exits 1 when `VERSION` isn't `MAJOR.MINOR.PATCH`.
    - Exits 0 otherwise, including on `main` itself, and when `<base-ref>` has no `VERSION` file, which counts as a bump.
  - `make release-zip`: a Release build to `build/release/Scratch.app`, then `ditto -c -k --keepParent` to `build/release/Scratch-<VERSION>.zip`.

**Behaviour:**
- **The release workflow** runs on `push` to `main` with `paths: [App/**, Packages/**, VERSION]`, on `macos-26` with Xcode 26.6.
  - If the tag `v<VERSION>` already exists, it stops successfully.
  - Otherwise it runs `make project release-zip`, then:

    ```sh
    gh release create v<VERSION> build/release/Scratch-<VERSION>.zip \
      --title "Scratch <VERSION>" --generate-notes \
      --notes-file docs/release-notes-footer.md
    ```

    If `gh` can't combine `--generate-notes` with `--notes-file`, build the notes by generating them first through the API, then appending the footer.

Because the app isn't sandboxed and uses no keychain or privacy-protected resources, a changing ad-hoc identity can't lock it out of its notes. That removes the owner's one-time certificate step. Record this, and that §11 step 2 no longer applies.
