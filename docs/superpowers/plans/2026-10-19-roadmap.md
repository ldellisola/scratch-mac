# Scratch roadmap

Spec: [`../specs/2026-10-19-scratchpad-design.md`](../specs/2026-10-19-scratchpad-design.md)

The design is built as six plans. Each one ships working, tested software and a GitHub Release.

Each plan after the first is written only once the previous one has merged, so that it can build on what actually exists, including the TextKit decision from Plan 1.

| # | Plan | Delivers | Spec sections | Release |
|---|---|---|---|---|
| 1 | **Walking skeleton**, [plan](2026-10-19-plan-1-walking-skeleton.md) | Toolchain and session setup. `ScratchCore` covers storage, autosave, session restore and fixtures. The app window has a glass sidebar, toolbar and one plain-text editor, with plain paste and plain copy. Also: the CI loop and `ci-results` branch, screenshots, the performance harness, the TextKit decision, and the release pipeline. | §5, §6.1 (partly), §6.5 (plain text only), §6.6, §7, §8, §9 | 0.1.0 |
| 2 | Notes and tabs | Title field, sidebar groups and pinning, search (FTS5), the tab strip and its behaviours, delete and Recently Deleted with 30-day purge, ⌘+/⌘− font size, all §6 shortcuts | §6.1–6.3, §6.4 (title, font size), §6.7 | 0.2.0 |
| 3 | Formatting | Marker parser in core, list editing rules, rendering of bullets, checkboxes, bold, inline code and links, ⌘B and ⇧⌘L, copy-out with markers | §6.4 (markers), §6.5 | 0.3.0 |
| 4 | Code | Code detection, tree-sitter highlighting, code blocks with a language label menu, paste classification | §6.4 (code), §6.5 (paste order) | 0.4.0 |
| 5 | Attachments | Attachment storage, paste, drag and paperclip, inline previews and chips, open and drag out, copy rules, purge | §6.4 (attachments), §6.5 | 0.5.0 |
| 6 | Polish and hardening | Performance budgets tightened against the baseline, accessibility pass, visual polish against the mockup, and a cold-boot check on a real Mac | §4, §7, §10 | 1.0.0 |
